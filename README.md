# Web Layout Portfolio - NCT Universe Information Page

Selamat datang di repository proyek portofolio saya. Proyek ini dikembangkan sebagai bagian dari tugas mata kuliah Desain Web untuk mendemonstrasikan pemahaman dan penerapan fundamental *front-end web development* menggunakan HTML5 dan CSS3.

## Deskripsi Proyek
Website ini adalah halaman web statis informatif yang dirancang dengan struktur layout klasik (Header, Navigation, Aside, Content, Footer). Proyek ini berfokus pada penerapan styling CSS yang rapi, tipografi kustom, dan interaksi pengguna dasar tanpa mengandalkan framework eksternal.

## Fitur Teknis
- **Semantic HTML5**: Penggunaan tag yang terstruktur untuk aksesibilitas dan SEO dasar.
- **Custom Typography**: Implementasi font kustom menggunakan CSS `@font-face` (Vogue.ttf & Giarek.ttf).
- **Complex Navigation**: Menu navigasi *dropdown* bertingkat menggunakan CSS `position` dan `hover` states.
- **Layout Management**: Pengaturan tata letak menggunakan CSS `float`, `margin: auto`, dan `box-shadow` untuk kedalaman visual.
- **Interactive UI**: Efek transisi halus (`transition`) pada elemen navigasi dan tautan saat di-*hover*.
